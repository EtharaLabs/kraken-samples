+        """
+        Compute the period t-statistics from a single QR decomposition
+
+        Parameters
+        ----------
+        endog : ndarray
+            The dependent variable of the auxiliary regressions.
+        exog : ndarray
+            The regressor matrix from ``_format_regression_data``. Only the
+            constant, lagged level and lagged difference columns are used.
+        regression : {"c", "t", "ct"}
+            The trend order to include in the regression.
+        periods : ndarray
+            The candidate break periods.
+        nobs : int
+            The number of observations in series.
+        trend : ndarray
+            The normalized trend values to use in exog.
+        cols : int
+            The number of non-lag columns in exog.
+        lags : int
+            The number of lagged difference terms included in exog.
+
+        Returns
+        -------
+        stats : ndarray
+            The t-statistic of the lagged level for each period. NaN for the
+            periods flagged in ``use_fallback``.
+        use_fallback : ndarray
+            Boolean array that is True for the periods that must be computed
+            by the per-period regressions instead.
+
+        Notes
+        -----
+        Only the break dummies change between periods. Let W hold the fixed
+        regressors (constant, trend and lagged differences), x the lagged
+        level and e the dependent variable, and let ``[W, x, e] = Q R`` be
+        the QR decomposition. After partialling out W, x is ``q_x r_xx`` and
+        e is ``q_x r_xe + q_e r_ee``, where ``q_x``, ``q_e`` are the last two
+        columns of Q. A dummy matrix D splits into ``Q g`` with ``g = Q'D``
+        and a part orthogonal to all of Q, whose cross product is
+        ``H = D'D - g'g = S'S``. In the orthonormal coordinates
+        ``(q_x, q_e, basis of the orthogonal part)`` the regression of e on
+        ``[D, x]`` after partialling out W has the small regressor matrix
+        ``[[g_x, r_xx], [g_e, 0], [S, 0]]`` and dependent variable
+        ``(r_xe, r_ee, 0)``. The trailing entries ``r11, r12, r22`` of the R
+        factor of this small regression give the t-statistic of x as
+        ``sqrt(df) * sign(r11) * r12 / |r22|``.
+
+        Every dummy is a step or a ramp starting at the break, so ``g`` is a
+        partial sum of the rows of Q (weighted by the row index for a ramp)
+        and ``D'D`` has a closed form. Adding constant and trend terms to D
+        does not change the regression, so the dummies are taken on the
+        shorter side of the break, which keeps their projection on the
+        constant and trend small. Periods where computing H by subtraction
+        loses more than half of the digits, or where x or e are explained
+        up to rounding, are flagged for the per-period regressions, as
+        are periods whose dummies wrap around the sample or lie in the span
+        of the constant and trend. All periods
+        are flagged if the data are not finite or there are too few
+        observations, and the first period is flagged if its regressors are
+        close to the rank deficiency that ``run`` checks there.
+        """

+        # right the step is 1 and the ramp is ``m - i`` in the rows
