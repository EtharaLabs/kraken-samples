+def _orthogonalize(q, d):
+    """
+    Split columns into their projection on an orthonormal basis and the rest
+
+    Parameters
+    ----------
+    q : ndarray
+        The orthonormal basis, (nobs, p).
+    d : ndarray
+        The columns to split, (nobs, g).
+
+    Returns
+    -------
+    w : ndarray
+        The coordinates ``q.T @ d`` of the projection, (p, g).
+    rho : ndarray
+        The triangular factor of the remainder ``d - q @ w``, (g, g).
+
+    Notes
+    -----
+    The remainder is orthogonalized twice, which makes it orthogonal to
+    ``q`` to working precision even if it is small relative to ``d``.
+    """
+    d = np.asarray(d, dtype=float)
+    w = q.T @ d
+    v = d - q @ w
+    w_v = q.T @ v
+    v -= q @ w_v
+    return w + w_v, np.linalg.qr(v, mode="r")

+        t-statistics of the lagged level for all candidate break periods
+
+        Parameters
+        ----------
+        endog : ndarray
+            The dependent variable of the auxiliary regressions.
+        exog : ndarray
+            The regressor matrix from ``_format_regression_data``.
+        regression : {"c", "t", "ct"}
+            The trend order to include in the regression.
+        periods : ndarray

+        nobs : int
+            The number of observations in series.
+        const : float
+            The normalized constant term value to use in exog.
+        trend : ndarray

+        cols : int
+            The number of non-lag columns in exog.
+        lags : int
+            The number of lagged difference terms included in exog.
+
+        Returns
+        -------
+        ndarray or None
+            The t-statistic of the lagged level in the regression of each
+            period. None if there are no periods, the data are not finite, a
+            break dummy wraps around or has too few nonzero rows, or a
+            regression is (almost) singular or fits (almost) perfectly. The
+            caller then fits the periods one by one.
+
+        Notes
+        -----
+        The regressors of period ``bp`` are ``X = [F, D, ylag]``, where
+        ``F = [const, trend, lags]`` does not depend on the period, ``ylag``
+        is the lagged level and ``D`` holds the break dummies. Their rows
+        ``r >= s``, with ``s = bp - lags - 1`` (``bp - lags - 2`` for "t"),
+        form the tail, the others the head. Only the span of ``X`` matters
+        for the t-statistic of ``ylag``, so ``D`` is replaced by
+
+        * "c": the step ``1{r >= s}``,
+        * "t": the hinge ``(r - s + 1) 1{r >= s}``,
+        * "ct": both.
+
+        As ``F`` contains a constant and a trend, these are interchangeable
+        with their head versions ``1{r < s}`` and ``(s - 1 - r) 1{r < s}``,
+        which differ from the tail versions by a linear function of ``r``.
+        The shorter side is used, which keeps ``D`` far from ``F``.
+
+        Let ``A = [F, ylag, endog] = QR``. Then ``D = Qw + v`` with
+        ``w = Q'D`` and ``v`` orthogonal to ``A``. Row sums of ``Q`` over
+        the head (prefix sums) and the tail (suffix sums) give ``w`` of the
+        steps for all periods at once. The hinges follow from a second
+        cumulative sum, since ``(s - 1 - r) 1{r < s}`` is the sum of
+        ``1{r < j}`` over ``j < s``, and ``(r - s + 1) 1{r >= s}`` that of
+        ``1{r >= j}`` over ``j >= s``. ``D'D`` is known in closed form and
+        ``rho'rho = D'D - w'w`` gives the triangular ``rho`` with
+        ``v = V rho`` for an orthonormal ``V``. The subtraction cancels when
+        ``v`` is small relative to ``D``; for those periods ``w`` and ``rho``
+        are computed from ``D`` itself, orthogonalizing twice.
+
+        With ``[A, D] = [Q, V] [[R, w], [0, rho]]``, the triangular factor
+        of ``[F, D, ylag, endog]`` has ``R[:m, :m]`` (``m`` columns in
+        ``F``) in its leading block and the triangular factor of
+
+            T = [[w[m:], R[m:, m:]], [rho, 0]]
+
+        in its trailing block. With ``r_xx``, ``r_xy`` and ``r_yy`` the
+        entries of the latter for ``ylag`` and ``endog``, the coefficient of
+        ``ylag`` is ``r_xy / r_xx``, its standard error is
+        ``|r_yy| / sqrt(df_resid) / |r_xx|``, and so the t-statistic is
+        ``sign(r_xx) r_xy sqrt(df_resid) / |r_yy|``.
