## Scoring

- Share: For one timed instance, s = T_base / T_patch and r = T_base / T_reference (minima over the repetitions, all builds timed in the same verifier run). A class's worst-case instance is the one with the smallest s over its two hidden sizes; the class share is 0 when that s < tau, else min(1, SR / opt_threshold) with SR = s / r at that same instance (the speedup ratio against the reference). A failed patch run in any instance of a class makes the class share 0.
- Credit: P = the class-weighted mean of the six class shares (string and arbitrary-object sentinels 0.40 each; plain, None, nan and mixed 0.05 each).
- Thresholds: tau = max(tau_floor, spread ** 2), spread = the largest ratio between the two base series' minima over every timed instance of the run; tau_floor = 2.0; opt_threshold = 0.95 (SWE-fficiency 2511.06090v3 speedup ratio against the expert (lines 380-391); GSO 2505.23671v3 OPT_0.95 success threshold (lines 311-312)).
- Items: When any gate G1 to G5 fails every item scores 0. Otherwise a timed-class item scores its class share min(1, SR / 0.95), and every other item scores 1.0 when its relation holds and 0 when it fails, where the relation of a prohibition (negate true) holds when the prohibited act is absent. The six timed-class items carry weight 5 each (30 of 45, two thirds of the compiled score) and the thirteen others 15 together, so C = (2/3) * P + (1/3) * (the weighted share of the non-timed items that hold).
- Reward: reward = 0 when any gate G1 to G5 fails; otherwise reward = 0.9 * C + 0.1 * J, where C is the weighted mean of the 19 compiled items (compiled_item_rule: two thirds speed credit P, one third correctness, constraint and craft items worth 1.0 each when they hold) and J the item-weighted mean of the judged items (each the median of 3 judge samples). ## Semantic notes

- Instances on which the base build itself raises (for example a pd_NA-like sentinel compared element by element, or sorting None or object sentinels in setdiff1d, union1d, setxor1d and unique) have no defined result to keep: the verifier records them per seed (base_raises) and does not grade them. The reference fix returns masks on several of them, which this rule allows.
- The reference fix promotes a fixed-width unicode operand to StringDType; fixed-width unicode drops trailing NUL characters, so a NUL-terminated string matches its stripped spelling at base but not after promotion. The hidden instances keep NUL-terminated strings only where every operand is StringDType, so both behaviours stay graded where they agree.
- The first timed call imports numpy.ma lazily on the sort path; every build site keeps the bytecode pip compiles at install, so base, reference and submission start alike (a first run without that bytecode in the image sites under-measured the reference by 2 to 3 times).
